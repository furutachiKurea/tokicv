# 领域文档

## 布局

本仓库采用 single-context 布局

- 根目录 `GLOSSARY.md`：领域术语
- `docs/adr/`：架构决策记录

## 阅读规则

探索代码前，阅读术语表和与当前任务相关的 ADR
文件尚未建立时继续工作，由 domain-modeling 技能在术语或决策确定后按需创建

## 术语规则

任务标题、重构建议、假设和测试名称中的领域概念，使用术语表定义的名称
遇到尚待定义的概念时，先核实项目用语，再将需要补充的术语交由 domain-modeling 处理

## 决策冲突

建议与已有 ADR 冲突时，明确指出对应 ADR，并说明重新讨论的理由
